## 6. Quick Notes

**Count lines in a text file:**
```python
def count_lines(textfile):
    with open(textfile, "r") as file:
        return sum(1 for s in file)

print(count_lines("textfile.txt"))
```

**Count words in a text file:**
```python
def count_words(textfile):
    with open(textfile, "r") as file:
        return len(file.read().split())

print(count_words("textfile.txt"))
```

**Run a FastAPI application:**
```bash
python -m uvicorn main:app --reload
```

**Run on a different port:**
```bash
python -m uvicorn main:app --reload --port 5000
```

**Basic FastAPI route:**
```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def home():
    return {"message": "Hello World"}
```

**Important terms:**
- `@app.get("/")`: Defines a GET route for the home path.
- `app = FastAPI()`: Creates the FastAPI application.
- `--reload`: Restarts the server when code changes are detected during development.
- `return`: Sends a result back from a function.
